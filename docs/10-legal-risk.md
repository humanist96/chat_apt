# 10. 법적 고려사항 및 리스크

## 10.1 크롤링 관련 법적 고려사항

| 항목 | 고려사항 |
|------|----------|
| robots.txt | 네이버 부동산 robots.txt 준수 |
| 이용약관 | 상업적 이용 시 법적 검토 필요 |
| 서버 부하 | 과도한 요청으로 인한 업무방해 주의 |
| 저작권 | 수집 데이터의 저작권 확인 |

### 관련 법률

| 법률 | 내용 |
|------|------|
| 정보통신망법 | 정당한 접근권한 없이 정보통신망 침입 금지 |
| 저작권법 | 데이터베이스 제작자의 권리 보호 |
| 부정경쟁방지법 | 타인의 상당한 투자나 노력으로 만들어진 성과 무단 사용 금지 |

### 준수 사항

```
1. robots.txt 준수
   - 크롤링 허용 여부 확인
   - Crawl-delay 준수

2. 서버 부하 최소화
   - 적절한 요청 간격 유지 (3-7초)
   - 피크 시간대 크롤링 자제

3. 데이터 사용 범위
   - 개인 연구/분석 목적
   - 원본 데이터 그대로 재배포 금지
   - 가공/분석 결과만 서비스
```

## 10.2 개인정보보호

### 수집 최소화

- 중개사 개인정보 수집 시 주의
- 불필요한 개인정보 수집 최소화
- 연락처 등 민감정보 마스킹 처리

### 개인정보 처리방침

```
1. 수집 항목
   - 필수: 이메일, 이름 (소셜 로그인 제공)
   - 선택: 관심 지역, 알림 설정

2. 수집 목적
   - 서비스 제공 및 회원 관리
   - 결제 및 구독 관리
   - 서비스 개선

3. 보관 기간
   - 회원 탈퇴 시 즉시 삭제
   - 법정 보관 의무 항목은 해당 기간 보관

4. 제3자 제공
   - 원칙적으로 제공하지 않음
   - 결제 처리를 위한 PG사 제공
```

## 10.4 리스크 및 대응방안

| 리스크 | 영향도 | 대응방안 |
|--------|--------|----------|
| 네이버 API 변경 | 높음 | 크롤러 모듈화, 빠른 대응 체계, API 변경 모니터링 |
| IP 차단 | 높음 | Proxy 풀 관리, 자동 로테이션, 차단 감지 및 복구 |
| 봇 탐지 | 높음 | 요청 패턴 인간화, User-Agent 로테이션, Playwright 활용 |
| CAPTCHA 출현 | 중간 | 요청 빈도 조절, 장기 휴식 전략, 필요시 CAPTCHA 솔루션 검토 |
| 공공API 호출제한 | 중간 | 캐싱 전략, 호출 최적화, 월별 시세 캐시 테이블 활용 |
| 데이터 정합성 | 중간 | 데이터 검증 로직, 모니터링, 이상치 탐지 |
| 유사도 계산 오류 | 중간 | 충분한 데이터 확보 (최소 1년), 검증 로직 |
| 법적 이슈 | 높음 | 법률 검토, 이용약관 준수, 개인 연구 목적 제한 |

## 10.5 리스크 대응 상세

### 크롤링 차단 대응

```python
class BlockRecoveryStrategy:
    """차단 시 복구 전략"""

    def __init__(self):
        self.recovery_attempts = 0
        self.max_attempts = 5

    async def handle_block(self):
        self.recovery_attempts += 1

        if self.recovery_attempts <= 2:
            # 1-2차: Proxy 교체 + 짧은 대기
            await self.rotate_proxy()
            await asyncio.sleep(30)

        elif self.recovery_attempts <= 4:
            # 3-4차: 세션 초기화 + 중간 대기
            await self.reset_session()
            await asyncio.sleep(300)  # 5분

        else:
            # 5차 이상: 장기 대기 + 알림
            await self.send_alert("크롤링 차단 감지")
            await asyncio.sleep(3600)  # 1시간
            self.recovery_attempts = 0
```

### 데이터 정합성 검증

```python
class DataValidator:
    """데이터 정합성 검증"""

    def validate_listing(self, listing: dict) -> bool:
        """매물 데이터 검증"""
        checks = [
            listing.get('price', 0) > 0,
            listing.get('area', 0) > 0,
            listing.get('floor') is not None,
            len(listing.get('apartment_name', '')) > 0,
        ]
        return all(checks)

    def detect_anomaly(self, price: int, avg_price: int) -> bool:
        """이상치 탐지 (평균 대비 3배 이상 차이)"""
        if avg_price == 0:
            return False
        ratio = price / avg_price
        return ratio > 3 or ratio < 0.3
```

## 10.7 면책 조항 (서비스 이용약관용)

```
본 서비스는 공공데이터와 공개된 정보를 기반으로 분석 결과를 제공합니다.

1. 정보의 정확성
   - 제공되는 정보는 참고용이며, 실제 거래 시 반드시 직접 확인하시기 바랍니다.
   - 실거래가는 신고 지연 등으로 실제와 다를 수 있습니다.

2. 투자 판단
   - 본 서비스의 분석 결과는 투자 권유가 아닙니다.
   - 투자에 따른 손실은 전적으로 이용자의 책임입니다.

3. 서비스 중단
   - 데이터 소스의 변경이나 기술적 문제로 서비스가 중단될 수 있습니다.
   - 서비스 중단에 따른 손해배상 책임을 지지 않습니다.
```
