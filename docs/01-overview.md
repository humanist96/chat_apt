# 1. 프로젝트 개요

## 1.1 목적

- 네이버 부동산의 매물 호가 정보와 공공데이터 실거래가를 수집하여
- 시세 대비 저평가된 최저가 매물을 자동으로 추천하는 시스템 개발

## 1.2 핵심 가치

| 가치 | 설명 |
|------|------|
| **정보 비대칭 해소** | 호가와 실거래가 비교를 통한 합리적 의사결정 지원 |
| **시간 절약** | 수동 검색 대신 자동화된 추천으로 효율성 증대 |
| **데이터 기반 분석** | 객관적인 수치 기반의 매물 평가 |
| **유사 매물 비교** | 동일 평형대 인근 아파트와의 시세 흐름 비교를 통한 저평가 매물 발굴 |

## 1.3 대상 사용자

### 일반 사용자 (Free)
- 아파트 구매를 고려하는 실수요자
- 시세 정보를 확인하고 싶은 일반인

### 개인 투자자 (Basic)
- 부동산 투자에 관심 있는 개인
- 저평가 매물을 찾는 투자자

### 전문 투자자 (Premium)
- 다수의 매물을 분석하는 전문 투자자
- API 연동이 필요한 개발자/사업자

## 1.5 기대 효과

### 사용자 관점
- 시세 대비 저렴한 매물 빠른 발견
- 유사 매물과의 객관적 비교를 통한 저평가 여부 확인
- 시세 흐름 차트를 통한 직관적인 가격 분석
- 객관적인 데이터 기반 의사결정
- 시간 및 노력 절감

### 기술적 관점
- 데이터 수집/분석 파이프라인 구축
- Anti-Abuse 회피 기술 경험 (크롤링 안정화)
- 시계열 데이터 상관관계 분석 역량
- 실시간 모니터링 시스템 경험
- 확장 가능한 아키텍처 설계

### 비즈니스 관점
- 서버리스 환경으로 초기 비용 $0 운영
- 구독 기반 안정적 수익 모델 구축
- 확장 가능한 SaaS 서비스 경험
- B2B API 제공을 통한 추가 수익원 확보

## 1.6 용어 정의

| 용어 | 정의 |
|------|------|
| 호가 | 매도자가 희망하는 판매 가격 |
| 실거래가 | 실제 거래가 체결된 가격 |
| 전용면적 | 실제 사용 가능한 면적 (공용면적 제외) |
| 평당가 | 1평(3.3m²)당 가격 |
| 저평가 | 유사 매물 대비 시세가 낮은 상태 |
