## 환경 변수 체크리스트

### 프론트엔드 (.env.local)
```env
NEXT_PUBLIC_SUPABASE_URL=          # ✅ 설정됨
NEXT_PUBLIC_SUPABASE_ANON_KEY=     # ✅ 설정됨
NEXT_PUBLIC_API_URL=               # ✅ 설정됨
NEXT_PUBLIC_TOSS_CLIENT_KEY=       # ✅ 설정됨
```

### 백엔드 (.env)
```env
DATABASE_URL=                      # ✅ 설정됨
SUPABASE_URL=                      # ✅ 설정됨
SUPABASE_SERVICE_KEY=              # ✅ 설정됨
TOSS_CLIENT_KEY=                   # ✅ 설정됨
TOSS_SECRET_KEY=                   # ✅ 설정됨
UPSTASH_REDIS_REST_URL=            # ⚙️ 코드 준비됨 (Upstash 콘솔에서 값 발급 필요)
UPSTASH_REDIS_REST_TOKEN=          # ⚙️ 코드 준비됨 (Upstash 콘솔에서 값 발급 필요)
TELEGRAM_BOT_TOKEN=                # ⚙️ 코드 준비됨 (@BotFather에서 발급 필요)
TELEGRAM_CHAT_ID=                  # ⚙️ 코드 준비됨 (@userinfobot에서 확인 필요)
SENTRY_DSN=                        # ⚙️ 코드 준비됨 (Sentry 콘솔에서 발급 필요)
SENDGRID_API_KEY=                  # ❌ 미구현
```
